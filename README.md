## Welcome

Streaming services evolve constantly.

URLs change.

Subtitle formats change.

Features that worked yesterday may stop working tomorrow.

Language learners shouldn't lose a valuable learning tool because of platform changes.

**AC forever** exists to keep subtitle enhancement working, improve the learning experience, and make long-term maintenance easier.

Welcome to the **AC forever Lab**.

---

## Features

- ✅ Enhanced Disney+ compatibility
- ✅ English-first subtitle layout by default
- ✅ Better compatibility with evolving streaming platforms
- ✅ Clean and maintainable patches
- 🚧 Better debugging tools *(planned)*
- 🚧 More platform improvements *(planned)*
